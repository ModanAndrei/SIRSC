Acesta este modulul care ne permite să interacționăm cu modelul antrenat.

Am folosit **Streamlit** pentru a face o aplicație web simplă și rapidă.
- Poți încărca fotografii cu semne rutiere.
- Sistemul îți arată unde este semnul și ce reprezintă el (cu nume în română).
- Am adăugat și o verificare de siguranță: dacă modelul nu e sigur pe ce a văzut, te avertizează.

Pentru a porni aplicația, rulează:
```powershell
streamlit run src/app/app.py
```
